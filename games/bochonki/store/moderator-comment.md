# Комментарий разработчика для модерации

Вставить в поле «Комментарий для модератора» в черновике игры.
Главная задача текста — снять вопрос по объёму контента (требование 2.9):
партия длится 3–5 минут, и без пояснения объём легко недооценить.

---

Здравствуйте!

«Бочонки» — игра по мотивам русского лото, состоящая из трёх связанных режимов.

**Режим 1. Классическое лото.** Полноценная партия с ведущим и двумя соперниками.
Карточка 3×9 по правилам русского лото: 15 чисел, по 5 в строке, числа в столбцах
соответствуют десяткам (1–9, 10–19, … 80–90). Бочонки достаются из мешка на 90 чисел
по одному, игрок отмечает свои числа и должен успеть до следующего бочонка —
пропущенное число отметить уже нельзя. Побеждает тот, кто первым закроет все 15.

**Режим 2. Карточка мастера.** Развитие того же материала: пустое поле 5×5 и 25 бочонков.
Бочонок достаётся из мешка, а игрок сам выбирает, в какую клетку его поставить.
Ход необратим, поэтому партия — это управление сужающимся пространством выбора.
Очки начисляются по трём независимым системам:
- строки — числа по возрастанию слева направо;
- столбцы — числа из одного столбца карточки лото (родство десятков);
- диагонали — числа одной чётности.

Правила открываются постепенно: в первой партии считаются только строки, во второй
добавляются столбцы, в третьей — диагонали. Это сделано, чтобы не перегружать игрока
тремя системами сразу.

**Режим 3. Барабан.** То же поле 5×5 и та же система очков, но вытягивание
становится решением: барабан выкатывает три бочонка сразу, игрок берёт один,
а два других возвращаются в мешок на случайные позиции и могут выпасть снова.
Под каждым кандидатом показано, сколько очков он даст на лучшей клетке, поэтому
выбор информированный. Отказ от бочонка — ставка на то, что он вернётся, когда
поле будет выгоднее.

**Объём контента.**
- Три самостоятельных игровых режима.
- Три системы подсчёта очков с постепенным открытием.
- Ежедневная партия: последовательность бочонков определяется датой по серверному
  времени и одинакова для всех игроков в сутки, поэтому таблица лидеров сравнивает
  решения, а не удачу.
- Свободная партия со случайной раздачей — неограниченное число повторов.
- Коллекция из 40 достижений.
- Личная статистика: рекорд, медиана, распределение результатов по последним
  30 партиям, серия дней подряд.

Одна партия занимает 3–5 минут, но полное открытие всех правил, коллекции достижений
и серии ежедневных партий — это десятки сессий. Игра рассчитана на возвращение,
а не на однократное прохождение.

**Обучение.** В меню есть экран «Как играть», построенный на схемах, а не на тексте:
миниатюрные поля с подсвеченными линиями показывают, за что начисляются очки,
рядом стоит конкретная сумма. Кроме того, во время партии каждая свободная клетка
всегда показывает, сколько очков даст постановка текущего бочонка, — правила
осваиваются за один ход, читать инструкцию не обязательно.

**Интеграция SDK.**
- `LoadingAPI.ready()` вызывается один раз сразу после первой отрисовки.
- `GameplayAPI.start()` / `stop()` расставлены по границам партии, в том числе вокруг
  показа рекламы.
- Полноэкранная реклама показывается только на экране результата между партиями,
  где геймплей объективно остановлен, и не после каждой партии. Внутри партии рекламы нет.
- Rewarded-видео вызывается исключительно по явному нажатию игрока (отмена хода,
  просмотр следующих бочонков), награда выдаётся только в колбэке `onRewarded`.
  Оба бонуса необязательны: партия полностью проходится без просмотра рекламы.
- Прогресс сохраняется в облако через `player.setData()` с ограничением записи
  не чаще одного раза в 5 секунд, плюс дублируется в localStorage.
- Таблицы лидеров: `daily` (партия дня), `best` (личный рекорд «Карточки мастера»)
  и `drum` (режим «Барабан» — вынесен отдельно, поскольку очки этих режимов несопоставимы).
- Для неавторизованных игроков вместо таблицы лидеров показывается локальная
  статистика — медиана и распределение собственных результатов.

**Платформы и управление.** Игра работает на десктопе (мышь и клавиатура) и на мобильных
устройствах (тач). Вёрстка адаптивная, горизонтальной прокрутки нет, зоны нажатия
не меньше 56 px, цифры на карточке не меньше 28 px — игра рассчитана в том числе
на возрастную аудиторию.

**Локализация.** Русский, английский, турецкий — переведены полностью, включая названия
всех достижений. Язык определяется через `environment.i18n.lang`.

**Технические характеристики.** Архив около 31 КБ. Растровых ассетов нет: вся графика
построена на CSS, звук синтезируется через Web Audio API. Внешние ресурсы не загружаются,
запросов к сторонним хостам нет. Игра запускается и остаётся играбельной, даже если
SDK платформы недоступен.
