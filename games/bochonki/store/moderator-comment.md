# Комментарий разработчика для модерации

Вставить в поле «Комментарий для модератора» в черновике.
Лимит поля — 2048 символов, текст ниже в него укладывается.
Главная задача — снять вопрос по объёму контента (требование 2.9):
партия длится 3–5 минут, и без пояснения объём легко недооценить.

---

«Бочонки» — русское лото и две игры, выросшие из него.

РЕЖИМЫ
1. Классическое лото. Карточка 3×9 по правилам русского лото, ведущий, два соперника. Своё число нужно успеть отметить до следующего бочонка.
2. Карточка мастера. Поле 5×5, 25 бочонков, клетку выбирает игрок, ход необратим. Очки: строки — за возрастание, столбцы — за родство десятков, диагонали — за чётность. Правила открываются по одному, чтобы не давать три системы сразу.
3. Барабан. То же поле, но барабан выкатывает три бочонка: один берёте, два возвращаются в мешок и могут выпасть снова.

ОБЪЁМ КОНТЕНТА (к требованию 2.9)
Партия идёт 3–5 минут, но содержимого заметно больше: три режима, три системы очков с постепенным открытием, ежедневная партия на общем для всех игроков мешке, коллекция из 40 достижений, личная статистика. Полное открытие — десятки сессий.

ОБУЧЕНИЕ
Экран «Как играть» на схемах, плюс во время партии каждая свободная клетка показывает, сколько очков даст постановка. Читать инструкцию не обязательно.

SDK
— LoadingAPI.ready() один раз, сразу после первой отрисовки.
— GameplayAPI.start/stop по границам партии и вокруг рекламы.
— Полноэкранная только на экране результата и не после каждой партии. Sticky-баннер — вне партии, на время игры скрывается. Внутри партии рекламы нет.
— Rewarded только по явному нажатию, награда по onRewarded: отмена хода и подсмотр бочонков, перекат барабана, возврат пропущенного числа. Все бонусы необязательны, любая партия проходится без рекламы.
— Сохранения через player.setData не чаще раза в 5 секунд, финальное — с flush=true.
— Лидерборды: daily, best, drum. Неавторизованным вместо таблицы показывается их локальная статистика.

ПЛАТФОРМЫ
Десктоп (мышь, клавиатура) и мобильные (тач), обе ориентации. Горизонтальной прокрутки нет, зоны нажатия от 56 px, цифры от 28 px — расчёт на возрастную аудиторию.

Язык определяется через environment.i18n.lang при запуске; локализация RU/EN/TR полная. Архив 39 КБ, растровых ассетов и внешних запросов нет. Игра работает и без SDK.
