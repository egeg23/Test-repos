# Требование 2.14 — автоопределение языка

Источник: https://yandex.ru/dev/games/doc/ru/requirements/2/14
Требование распространяется на все игры, даже с одним языком и вовсе без текстов.
Модерация проверяет каждый заявленный язык через debug-панель.

## Что уже соответствовало

- Код языка берётся из `environment.i18n.lang` при инициализации SDK.
- Определение происходит **до первой отрисовки**, а не в процессе игры.
- Неподдерживаемый язык откатывается на резервный, интерфейс не ломается.

## Что исправлено

### Сохранённый язык мог перебить язык платформы

Было: `save.lang || sdk.state.lang`. Поле `save.lang` объявлено в структуре
сохранения, но нигде не записывалось, поэтому пока работало верно.

Это мина. Стоит появиться переключателю языка внутри игры — и кэш начнёт
перебивать платформу. Модерация переключает языки через debug-панель и увидит,
что интерфейс не меняется: отказ по 2.14.

Стало: язык берётся напрямую из состояния SDK, поле из сохранения убрано.
Кэширование языка требование допускает, но не ценой приоритета над платформой.

### Аварийный экран был только на русском

Если запуск падал, показывалась захардкоженная строка «Не удалось загрузить игру».
Непереведённая строка на любом из заявленных языков — нарушение 2.14. Переведена
на все три языка, язык подставляется даже в аварийном пути.

### Локализация требовала DOM

`setLang` обращался к `document` напрямую, из-за чего модуль нельзя было проверить
тестами. Обращение к DOM теперь условное.

## Проверка

| Язык от SDK | Результат |
|---|---|
| `ru` | русский, `<html lang="ru">` |
| `en` | английский |
| `tr` | турецкий |
| `de`, `zh`, `pt-BR` | откат на английский |

Отдельно проверено, что смена языка между заходами подхватывается —
именно так проверяет модерация. Закреплено четырьмя тестами.

## Что осталось намеренно

- Загрузочный экран показывает букву «Б» до инициализации SDK.
  Требование это прямо допускает: «Загрузочный экран временно на другом языке».
- Сообщения валидатора карточки лото на русском — они внутренние,
  игроку не показываются и используются только тестами.
