# Сверка рекламы с документацией SDK

Источник: https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv (проверено 17.08.2026).
Каждый пункт проверен запуском, а не чтением кода.

## Что было верно изначально

| Пункт | Статус |
|---|---|
| Форма вызова `{ callbacks: {...} }`, а не сразу объект колбэков | верно |
| `onClose(wasShown)` у полноэкранной — используется значение параметра | верно |
| `onError` обработан у обоих типов | верно |
| Награда выдаётся только в `onRewarded` | верно |
| Полноэкранная — после действия игрока, не во время взаимодействия | верно |

Форма вызова — главный риск: в сигнатуре из документации параметр назван
`callbacks`, и по ней легко передать колбэки напрямую. В примерах платформы
аргумент обёрнут: `showFullscreenAdv({ callbacks: { ... } })`. У нас так и было.

## Что исправлено

### ADV-001 — игра могла зависнуть, если SDK промолчит

Если не приходит ни `onClose`, ни `onError`, продолжение не наступало никогда:
после партии игрок оставался на застывшем экране.

Добавлен сторож на 8 секунд. Приходит `onOpen` — сторож снимается, иначе он
оборвал бы реально идущий ролик (rewarded длится дольше). Проверено на молчащем
SDK: через 9 секунд игра принимает ходы и партия доигрывается до результата.

### ADV-002 — звук не приглушался на время рекламы

Добавлен `onOpen`: приостанавливаем аудиоконтекст и возвращаем его при закрытии.
Настройку звука игрока это не трогает — приостанавливается сам контекст.

### ADV-003 — `onClose` и `onError` могли сработать оба

У rewarded не было защиты от повторного завершения: продолжение выполнялось дважды.
Добавлен флаг, как у полноэкранной.

### ADV-004 — sticky-баннер не использовался вообще

Третий формат из трёх не был подключён, хотя баннер появляется по умолчанию
при запуске и управляется через API.

Подключён: `showBannerAdv` на экранах вне партии, `hideBannerAdv` на время игры.
Поле 5×5 и карточка лото занимают экран целиком, и баннер поверх них мешал бы
попадать по клеткам. Проверено: `banner.show → banner.hide → banner.show`.

## Итоговая карта показов

| Где | Формат |
|---|---|
| Меню, обучение, коллекция, статистика, результат | sticky-баннер |
| Экран результата, не после каждой партии | полноэкранная |
| Карточка мастера: отмена хода, подсмотр трёх бочонков | rewarded |
| Барабан: перекат тройки | rewarded |
| Лото: возврат пропущенного числа | rewarded |
| Внутри партии | ничего |

Все rewarded вызываются только по нажатию игрока и необязательны: любая партия
проходится без единого просмотра. Если реклама недоступна, бонус выдаётся
бесплатно — игра не должна ломаться из-за незагрузившегося ролика.
